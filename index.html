Operating model

Build → verify → deploy.

A professional workflow is simple: make the change, prove it works, deploy it safely, then document the result. Patience and verification beat chaos every time.

01 · Develop

Clear source

Small, readable HTML/CSS/infra changes in Git with the deployment workflow stored beside the site.

02 · Preview

Check the system

Validate content, endpoint responses, AWS identity, bucket contents, and public HTTP status before calling work done.

03 · Ship

Deploy cleanly

Push to main, run CI/CD, sync S3, invalidate CloudFront, and verify the production domain after the pipeline finishes.
