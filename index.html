/ workflow

A professional workflow is simple: make the change, prove it works, deploy it safely, and document the result.

01 · Develop

Clear source

Small, readable HTML, CSS, application, and infrastructure changes in Git with the deployment workflow stored beside the code.

02 · Preview

Check the system

Validate content, automated tests, endpoint responses, AWS identity, and container health before calling work done.

03 · Ship

Deploy cleanly

Push to main, run CI/CD, sync S3 or EC2, invalidate CloudFront, and verify the production domain after the pipeline finishes.
